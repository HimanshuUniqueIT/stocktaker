One job, end to end

Stocktake Workflow

The day-to-day job workflow, and how the system runs it on site — one laptop, a private Wi-Fi router, and three Honeywell scanners.

The job, stage by stage

1

Requirement

Back office
  1. Client sends a stocktake requirement — site(s), count date, whether printed location sheets are a contract term, and whether they will supply a book stock file (their expected quantities).
  2. Client sends the product file — barcodes → product codes → descriptions. On an old site some lines arrive with no description and are entered by hand later.
  3. Back office creates the job for that client and pushes the product file out, so every laptop used on the job holds the same database.
2

Setup

On site
  1. Team sets up the laptop(s) and handheld scanners and opens the job.
  2. Build the location map — enter the location-ticket range, e.g. 9.002 to 9.084. Each ticket is one countable area: a shelf, a bay, or a zone. Mark any ticket that will not be used.
  3. Define groups if needed — e.g. Stockroom / Bunker / Shop floor, with a location range assigned to each. A single flat storage area needs no groups.
  4. Assign a range of location tickets to each counter.
3

Counting

On site
  1. Counters scan their locations. Single scan — one barcode is one unit (clothing, retail). Multi scan — scan the item, then key in the quantity (grocery, bulk).
  2. Each finished location is closed off — recorded against the counter and device (e.g. Omar, location 9.002, 81 units).
  3. Supervisor tracks coverage — green completed, white not started. A start-to-end range check flags any location missed in between as “waiting”.
  4. If two people counted the same location it is flagged “duplicate” for the supervisor to resolve.
4

Amend & check

On site
  1. Corrections are made from the laptop — adjust a quantity, add a barcode the counter missed (with its location and quantity), or delete a line / set it to zero. The location total recalculates.
  2. Print checks (if in the contract) — print each completed location’s sheet. Printed locations tick as “printed”, so outstanding sheets stay visible.
5

Consolidate

On site → back office
  1. If more than one laptop was used — each exports its data file; the files are imported onto one laptop and the data merges into a single complete set for the job.
  2. Final checks — every location green or genuinely unused, no open duplicates, no “waiting” gaps.
  3. The consolidated job file goes back to base (USB or sent in), so the back office can produce the paperwork even if a site laptop had a problem.
6

Reporting

Back office

Generated from the consolidated job file:

  • Audit report (Excel) — line detail: location, counter, date, client, product code, description, quantity. Multi-scans consolidated into one quantity per item. Always produced.
  • Summary report — units by location, subtotals by group, grand total (e.g. 9,655 units). The client’s headline figure.
  • Comparison report — a product’s quantity across groups (e.g. Stockroom vs Bunker), where groups were used.
  • Variance report — only with a book stock file: counted quantities vs the client’s expected quantities, listing the discrepancies.
7

Handover

Back office
  1. Reports are sent to the client, with the printed location sheets if those were part of the contract.
  2. The job is closed. The client stays on the client list for future counts.
Contract-dependent steps: printed location sheets (stage 4) are produced only when the contract calls for them; the variance report (stage 6) is produced only when the client supplies a book stock file.

Running it on site, step by step

One laptop runs the app and holds the one master list. A TP-Link router makes a private Wi-Fi called STOCKTAKE — it only needs a power socket and is not connected to the client’s Wi-Fi or the internet. The three Honeywells join that Wi-Fi and open the app in a browser.

Set up once — at your office

  1. In the TP-Link settings, set the Wi-Fi name to STOCKTAKE with a password. Leave the internet (WAN) socket unused.
  2. Reserve a fixed address for the laptop — “Address Reservation” → 192.168.0.10 — so the scanners always find it.
  3. Install the app on the laptop and set it to start automatically. It runs a small web server on the laptop itself.
  4. On each Honeywell: join STOCKTAKE Wi-Fi, open the browser at http://192.168.0.10:5000, add it to the home screen.
  5. Test — all three scan a few barcodes and you see them land on the laptop.

Job day — arrival (about 3 minutes)

  1. Plug the TP-Link into a power socket near where you will count. Switch it on.
  2. Plug in the laptop, open the lid — the app is already running. Connect it to the router (network cable is most reliable; Wi-Fi is fine).
  3. Turn on the 3 Honeywells — they remember STOCKTAKE Wi-Fi and open the app on their own.

Job day — start the job

  1. On the laptop, create the job for the client and load the product file.
  2. Build the location map (e.g. 9.002–9.084) and set groups if the site uses them.
  3. Assign a location range to each of the three counters. Each Honeywell pulls its list plus a copy of the product file, kept on the device.

Counting

  1. A counter selects a location (or scans its label). It turns amber — in progress on your screen.
  2. They scan items — single scan (1 barcode = 1 unit) or multi scan (scan, then key the quantity).
  3. Each scan is saved on the Honeywell first, then sent over STOCKTAKE Wi-Fi to the laptop at 192.168.0.10, onto the one master list. Your progress screen updates live.
  4. A spot with no Wi-Fi? The Honeywell holds the scans and sends them when back in range. Each scan has an ID, so a resend never double-counts.
  5. The counter closes the location — it turns green on your screen.

Watch & fix — on the laptop

  1. Track the grid — green done, white waiting, amber in progress, red duplicate.
  2. Range check — enter 9.002–9.084; anything untouched in between shows as “waiting”.
  3. Amend — change a quantity, add a missed barcode (with location + quantity), or delete / zero a line. Totals recalculate.
  4. Duplicate (two counters, one location) — open it, see both, choose Merge / Keep one / Delete both.
  5. Print checks (if contracted) — print each completed location; printed ones tick as “printed”.

Finish on site

  1. Confirm every location is green (or genuinely unused), no open duplicates, no “waiting” gaps.
  2. Confirm each Honeywell shows “0 unsent”.
  3. Export the job file to a USB stick as a backup. The laptop has also been auto-saving a copy every few minutes.

Back at the office

  1. Open the job file (or the laptop) and generate the reports — audit (Excel), summary, comparison, and variance (variance only if a book stock file was supplied).
  2. Email the reports to the client, with the printed sheets if they were in the contract. Close the job.

If something goes wrong

  • Laptop dies mid-count. Start the app on the spare laptop, load the latest auto-saved copy; the Honeywells reconnect to the same Wi-Fi and you carry on. The Honeywells still hold their own recent scans too.
  • A Honeywell breaks. Its synced scans are safe on the laptop; a replacement device logs in and picks up the unfinished locations.
